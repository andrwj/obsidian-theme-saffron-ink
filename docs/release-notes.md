# Saffron Ink 1.0.0

The first Obsidian release brings Saffron Ink's warm paper palette, crisp dark text, blue headings, and restrained golden accents to a light theme.

- Six heading weights: 800, 700, 600, 500, 400, and 300.
- Bolder folder names with a balanced blend of heading blue and explorer text color.
- Reading, Live Preview, and source styles for Markdown and code.
- User-selected fonts and text sizes, without bundled fonts or network assets.
- An optional GlyphIt preset for Font Awesome Free Regular folder and file icons.

Requires Obsidian 1.14.4 or later. Tested on macOS desktop; mobile has not yet been verified. GlyphIt and Font Awesome are optional and installed separately.

Install by placing the attached `theme.css` and `manifest.json` in `<Vault>/.obsidian/themes/Saffron Ink/`, then select Saffron Ink and Light mode under Appearance.
