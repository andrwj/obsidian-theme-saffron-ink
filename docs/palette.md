# Saffron Ink 색상과 제목 규칙

색상의 기준은 VS Code 원본의 역할입니다. Obsidian 고유 UI에는 동일한 팔레트에서 파생한 색상을 사용합니다.

| 역할 | 색상 | 적용 |
| --- | --- | --- |
| 종이 | #eddfb7 | 본문과 사이드바 |
| 보조 종이 | #e5d5a7 | 코드, 표 머리글, 탭 영역 |
| 잉크 | #000000 | 본문과 주요 텍스트 |
| 입력 커서 | #d73a49 | 일반 입력 커서와 Vim 블록 커서, VS Code 원본의 editorCursor.foreground |
| 보조 텍스트 | #4f5a63 | UI와 코드 주석 |
| 흐린 텍스트 | #756a50 | 부가 정보 |
| 사프란 | #8a6d24 | 활성 요소, 버튼, 포커스 |

| 파랑 | #004a9f | 제목, 링크, 상수 |

| 짙은 파랑 | #06264f | 문자열 |

## 제목의 굵기

H1부터 H6까지 800, 700, 600, 500, 400, 300을 사용합니다.
크기와 색상이 함께 계층을 나타내므로 H5와 H6의 낮은 굵기에서도 제목을 구분할 수 있습니다.
제목의 굵기는 Obsidian의 --h1-weight부터 --h6-weight까지 지정합니다.
이 변수는 읽기 모드와 CodeMirror의 제목 스타일에 적용됩니다.

글꼴 가족과 wght 축은 지정하지 않습니다. Pretendard Variable 같은 가변 글꼴과 여러 굵기가 설치된 JetBatang NF 같은 정적 글꼴을 모두 사용자가 선택할 수 있습니다.
굵기 파일이 일부만 설치된 글꼴에서는 브라우저의 대체 선택에 따라 차이가 줄어들 수 있습니다.

## 조정 기준

종이 배경과 검은 본문을 우선 유지합니다. 활성 UI는 사프란, 문서 제목과 링크는 파랑으로 구분합니다.
파일 탐색기의 폴더 이름은 --si-folder-weight의 600을 사용합니다. 일반 파일 이름의 기본 굵기는 변경하지 않습니다.
폴더 색상은 현재 일반 탐색기 텍스트 #4f5a63과 H1 파랑 #004a9f를 sRGB에서 50:50으로 혼합합니다. 약 #285281의 청회색입니다.
구문 강조는 가능한 범위에서 원본 토큰 역할을 대응시키며 언어별로 모든 TextMate 규칙을 재현하지는 않습니다.
다크 모드 전용 팔레트와 커뮤니티 플러그인별 전용 스타일은 후속 작업입니다.
